# Paham Syariah

Aplikasi web untuk belajar ekonomi syariah dengan bahasa sederhana. Cocok untuk pelajar, mahasiswa, dan masyarakat umum.

## Cara menjalankan

```bash
npm install
npm run dev
```

Untuk build produksi:

```bash
npm run build
```

Tidak ada variabel lingkungan rahasia yang dibutuhkan. Supabase sudah terkonfigurasi otomatis.

## Fitur

- 12 modul belajar dengan 91 materi
- Kamus 90 istilah dengan tulisan Arab
- Kuis 10 soal acak dengan opsi yang diacak
- Simulasi pilih akad (14 skenario)
- Bagi hasil atau bunga?
- Kalkulator cicilan murabahah
- Pencari Materi (pencarian lokal dari konten aplikasi)
- Papan peringkat
- Mode gelap, ukuran huruf, kontras tinggi
- Bacakan materi (Web Speech API bahasa Indonesia)
- PWA — bisa ditambahkan ke layar utama

## Sumber materi

11 sumber (1 buku Bank Indonesia & MUI, 1 buku pengantar, 9 jurnal, 1 catatan kuliah).
Lihat halaman Sumber dan Referensi di aplikasi untuk daftar lengkap.

## Catatan

Materi edukasi, bukan fatwa. Semua isi ditulis ulang dengan kalimat sendiri.
